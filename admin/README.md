# KIDIip Admin Dashboard

This is the React JS Admin panel built with Material UI (MUI) to manage categories and prompts.

## Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (recommended version matching Node v20+ or v22+).

---

## Installation & Setup

1. **Navigate to the admin directory**:
   ```bash
   cd admin
   ```

2. **Install all required dependencies**:
   ```bash
   npm install
   ```

---

## Running the Application

To start the local development server:

```bash
npm run dev
```

Once running, open your browser and navigate to:
👉 **[http://localhost:5173/](http://localhost:5173/)**

---

## Building for Production

To build the static assets for production deployment:

```bash
npm run build
```

The output files will be generated in the `dist` directory.
